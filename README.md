# Portfolio

Personal portfolio site for Christopher Goodale — engineer and data specialist.

Built with React + Vite, deployed to GitHub Pages via GitHub Actions.

**Live site:** https://christophergoodale.github.io/portfolio/

## Featured projects

- [Resume Generator](https://christophergoodale.github.io/resume_work/) — AI-assisted, job-tailored resume pipeline ([repo](https://github.com/ChristopherGoodale/resume_work))
- [Prediction Arbitrage Bot](https://christophergoodale.github.io/prediction_arbitrage_bot/) — cross-market pricing inconsistency detector ([repo](https://github.com/ChristopherGoodale/prediction_arbitrage_bot))

## Development

```bash
cd client
npm install
npm run dev
```
